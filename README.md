# YuvaIntern Logistics Data Analyst — Week 1

## Strategic Planning and Data Exploration in Logistics

This project demonstrates an introductory Python workflow for logistics KPI planning using a simulated shipment dataset.

### Files
- `code/week1_planning_example.py` — calculates illustrative KPIs.
- `data/logistics_simulated_clean.csv` — 300 synthetic shipment rows.
- `Week1_Strategic_Planning.docx` — Week 1 report.

### Run
Install Python 3 and pandas:
```bash
python -m pip install pandas
```
From the project folder, run:
```bash
python code/week1_planning_example.py
```
The code's 24-hour on-time threshold is illustrative only. The CSV is synthetic and not real shipment data.
